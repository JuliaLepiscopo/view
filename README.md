# 🏢 Flat
> *O caminho mais simples para encontrar o seu novo endereço.*

## Sobre o Projeto
O **Flat** é um aplicativo mobile focado no mercado imobiliário. O projeto simplifica a busca por casas e apartamentos, conectando compradores, inquilinos e corretores de forma rápida, transparente e intuitiva.

## Funcionalidades
* Busca Inteligente: Filtre imóveis por localização, faixa de preço, metragem e número de cômodos.
* Agendamento Direto: Marque visitas a imóveis diretamente pelo aplicativo com poucos cliques.
* Chat Integrado: Canal de comunicação ágil e seguro entre clientes e proprietários ou corretores.
* Favoritos: Salve e compare as melhores opções de moradia encontradas na sua jornada.
